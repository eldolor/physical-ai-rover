# 3.229 The brain's safety check gets the body's self box

*`PLAN-ros-alignment.md` section 3.229; index: [README.md](README.md).*

**Why.** 3.228's cause 1 and fix F1 (`3.228-trip-home-fails.md`, on its
branch `plan/3.228-trip-home-fails` when this was written): on the Rover
the brain's own `SafetyController` has no lidar self box, so the mast's
returns read as an obstacle at 0.0 cm. 3.218.A gave the brain the server's
box through `RemoteRobot.lidar_self_box_cm()`, which `_body_self_box()`
reads off `type(robot)`; but `MissionRunner` hands the agent
`_HaltGate(robot)`, which has no such method, so the agent's controller --
and `ReturnTrip`, built on `agent.safety` -- got `self_box_cm = None`.
Explore's escape (REVERSE refused at 0.0 cm `scan_rear`, FORWARD at 0.0 cm
`scan_footprint`, then a full circle) and the return's back-off were
refused in the brain and never sent: 12 of 12 escapes in the Rover's
2026-11-27 surveys. 3.218's test built a bare `RemoteRobot` and never went
through the runner, so the suite stayed green.

**Scope.** `_HaltGate` passes the wrapped body's `lidar_self_box_cm()`
through, and nothing else changes: the box's geometry, `self_box()`'s
checks and the robot server's controller (which keeps the last word, rule
4) are untouched. A body with no box answers None through the gate, as
before. Other wrappers on the brain's robot path: `_HaltGate` is the only
`RobotInterface` wrapper in `control/` and `brain/` (`_GatedNavigator`
wraps the navigator, not the body).

**Criteria (written 2026-11-27 before building; CLAUDE.md section 7).**
The body: the simulator (`scaled_house`, its start on open floor) with the
recorded mast returns (`evaluations/lidar-self-box-3218/`, median) put
into every scan and the Rover's box (-7.1, 3.2, -10.7, 8.5) reported, built
through `MissionRunner(policy="explore")` -- the real path; the "server's"
answer is a `SafetyController` given the box as `robot/server.py` gives it.

1. The brain's `forward_clearance()` and `reverse_clearance()` (the agent's
   `safety`, which `ReturnTrip` is built on) equal the server's, value and
   source; forward is not 0.0 `scan_footprint` and reverse is
   `astern_occluded`, not 0.0 `scan_rear`.
2. Explore's escape round (`_queue_escape` then its pending moves, through
   the real vet): REVERSE is refused only as the server refuses it
   (`astern_occluded`), and a FORWARD reaches the body. The return's
   back-off (`ReturnTrip._back_off`, on `agent.safety`) is refused only as
   `astern_occluded`, and its forward nudge reaches the body.
3. A body with no self box: the gate answers None, the agent's controller
   has no box, and its clearances equal a plain `SafetyController`'s.
4. The suite's existing safety tests pass unchanged (no edit to any of
   them).

Each of 1-2 fails before the fix (red first).
