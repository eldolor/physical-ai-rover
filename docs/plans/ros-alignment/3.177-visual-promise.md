# 3.177 Visual promise: does a frame say the target is near before it is in view

*`PLAN-ros-alignment.md` section 3.177; index: [README.md](README.md).*

**Why.** (the user, 2026-11-12: features of similar products and projects worth
building while the Rover waits on Waveshare.) VLFM (Boston Dynamics AI
Institute, ICRA 2024; run on a Spot in an unseen building) is the published
system closest to explore's design. Its one idea this project lacks: each
camera frame is scored for how well it matches the target's text, the score is
painted onto the map where the camera looked, and frontiers are ranked by it.
`docs/policy/ARCHITECTURE.md` already lists "visual promise" as a planned input
to goal choice, and nothing has measured it.

Why it may work where earlier attempts failed: 3.80 found that no model, asked
for a search **direction** from one out-of-view frame, beats naming the
commoner side (best 41% against 43%). A promise score asks less: not "which
way", only "does this view look like where the target would be", summed over
views on the map. And 3.103 closed the learned chooser with "the facts are the
limit": this is a new fact, from real perception, which the simulator's frames
cannot supply.

**Scope.** Offline and free first, on frames already recorded; nothing is
built into explore until the signal is shown to exist.
* A: on 3.92's labelled rig walks (2,261 frames, 21 walks), CLIP RN50's
  image-text score for the walk's target on frames with the target **out of
  view**. Does the score rise in the stretch before the target comes into view,
  against the same walk's frames far from it? No model call is paid; perception
  rows follow P24 (no GPU and CPU rows mixed).
* B, only if A meets its bar: the score painted on the map and given to goal
  choice as one more fact, judged on the Rover's own walks (the sim's renderer
  is not evidence for this).
* The cost on the board is a bar too: CLIP's image tower already runs per crop;
  a whole-frame pass is extra time and no extra model.

**Criteria (written in step A, before measuring; CLAUDE.md section 7).** At
least: the frame set pinned; a ranking measure (AUROC of "target comes into
view within k frames" from the score, per walk and pooled, with a bar above
chance and a per-object floor); the same for a shuffled-target control (must
sit at chance); extra milliseconds a frame on the Jetson at 15 W. A failed bar
closes the section as failed, recorded.
