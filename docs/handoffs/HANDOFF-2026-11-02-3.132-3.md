## What Stage 3 is

The plan's Stage 3 text has the scope: the twin's tabs, regrouped around
audience A, the person at home. Write its criteria into the section
**before** building.

**What 2B leaves for it.** Each of the following is a design change, not a
move:
* **The rest of `app.js` cannot move without changing code.** The sections
  use the voice helpers (`t`, `engineerMode`), the robot client (`apiGet`,
  `apiPost`), element constants read at the top level, or each other, in
  cycles. The 2B results list each one and what keeps it there.
* **The next easy move is the robot client** (75 lines, uses nothing from
  `app.js`). The mover refused it only for a template literal: check that
  the literal is on one line, then move it.
* **Two `let`s are written by a section other than the one declaring
  them:** guidance writes `reportToken`, and setup sharing writes
  `qrHideTimer`. Move each writer with its declaration, or give it a
  setter.
* **`voicedStatus` (`js/connstatus.js`) is exported,** though it was a
  private registry.
* **A module that fails to load runs none of `app.js`** (Stage 5's
  question).
